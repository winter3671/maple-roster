# 작성 중인 입력 보호

v0.2.5부터 저장하지 않은 입력이 있을 때 메뉴 이동, 취소, 팝업 닫기(X·Esc), 앱 종료와 업데이트 재시작 전에 확인한다. 변경하지 않은 입력이나 원래 값으로 되돌린 입력은 확인하지 않는다. 저장 중에는 화면 이동과 종료를 허용하지 않는다.

## 적용 범위

| 입력창                                                                             | 메뉴 이동 시                   | 취소·닫기 시           |
| ---------------------------------------------------------------------------------- | ------------------------------ | ---------------------- |
| 새 사냥 빠른·상세 기록, 수익·지출 추가, 수동 캐릭터 등록                           | 확인 후 앱 실행 동안 임시 보관 | 확인 후 임시 입력 폐기 |
| 기존 장부·캐릭터·보스 수정, 보스 추가, 드랍 획득·판매, API 보스 확인의 사용자 변경 | 확인 후 변경 폐기              | 확인 후 변경 폐기      |
| API 키·계정 이름 등록, 계정 이름 변경                                              | 확인 후 변경 폐기              | 확인 후 변경 폐기      |

새 입력은 원래 입력창을 다시 열면 복원 안내와 함께 나타난다. 상세 사냥 입력은 상세 기록 버튼, 수익·지출은 해당 추가 버튼을 눌러 이어 쓴다. 임시 입력은 **실제 장부에 자동 저장되지 않으며 앱을 종료하면 사라진다.** 기록 저장 버튼을 눌러야 수입·지출과 통계에 반영된다. 조회 조건과 필터는 입력 보호 대상에 포함하지 않는다.

API 키는 임시 입력 보관 대상에서 제외한다. 키 등록 시 입력란을 즉시 비우는 기존 보안 동작은 유지한다. 일반 장부의 저장 실패·입력 검증 실패는 입력을 유지하며, 성공한 저장만 변경 상태와 임시 입력을 해제한다.

## 구현

- `InputProtectionProvider`가 현재 입력창의 변경·저장 상태와 확인창을 관리한다. 팝업 닫기는 그 팝업 안의 입력만 검사하여 배경 입력을 함께 폐기하지 않는다.
- `useFormProtection`은 사용자 조작 이후의 값과 기준값을 비교한다. 최초 데이터 로딩과 기본 캐릭터 선택은 사용자 변경으로 취급하지 않는다. 저장 시작 시 React 재렌더를 기다리지 않고 저장 상태를 잠그고, 실패하면 변경 상태를 유지한다.
- `useProtectedDraft`와 `InputProtectionStore`는 새 입력 다섯 종류만 메모리에 보관한다. 파일·localStorage·DB·백업으로 내보내지 않는다. 메뉴에서 내려간 초안도 앱 종료 확인 대상이다.
- Electron 기본 창 닫기를 가로채 렌더러에 확인을 요청한다. 승인 IPC는 해당 창의 메인 프레임에서만 허용하며, 진행 중인 다른 IPC 작업을 확인하고 실제 종료 직전에 다시 검사한다. 렌더러 프로세스가 종료된 경우 창을 닫을 수 있도록 보호 대기를 해제한다.
- 업데이트 설치도 입력 확인을 거친다. 설치가 시작된 상태에서만 중복 종료 확인을 생략하며, 설치 오류 상태로 바뀌면 일반 종료 보호가 다시 적용된다.

## 검증 기록

2026-10-11, 타입 검사와 Electron 빌드 성공. 전체 테스트 **435개 통과**, 기존 성능 벤치마크 3개는 기본 실행에서 제외. 입력 보호 저장소 테스트 7개와 종료 승인 IPC 테스트 3개를 추가했다.

실제 Electron 앱을 별도 임시 장부로 실행해 다음 동작을 확인했다. 실제 사용자 장부와 API 키는 사용하지 않았다.

- 메뉴 이동 취소 및 사냥 메소·조각 입력 복원, 저장 성공 후 입력·보호 상태 해제
- 수익·지출 입력창 간 전환 시 수익 초안 복원, 명시적인 변경 폐기 후 빈 입력창
- 지연된 저장 중 창 종료 차단, 저장 실패 후 입력 유지, 창 종료 확인 취소
- API 키 입력 후 메뉴 이동 확인 및 복원 제외
- 캐릭터 수정 팝업 X·Esc 보호와 배경 새 캐릭터 입력 보존
- 메뉴에서 내려간 초안의 종료 확인, 원래 값으로 복원 후 확인 생략, 변경 없는 창의 정상 종료

검증은 강제 프로세스 종료나 OS 종료 시 초안 복구를 보장하지 않는다. 임시 입력을 앱 재실행 이후까지 보관하는 기능은 이번 범위에 포함하지 않는다.
