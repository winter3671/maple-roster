# 드랍 획득과 부분 판매

사냥·보스 기록의 **드랍 관리**에서 획득 묶음별로 수량과 예상 단가를 기록한다. 사냥의 솔 에르다 조각·코어 젬스톤은 회차 수량에 따라 자동 생성하고, 그 수량은 사냥 회차에서 수정한다. 기타 아이템은 이름을 직접 입력한다. 자동 시세 조회와 경매장 연동은 제공하지 않는다.

## 판매와 분배

메소 입력란 아래에는 `572만 5,459 메소`, `1억 2,345만 6,789 메소`처럼 만·억·조 단위로 금액을 실시간 표시한다. 조각의 개당·총 판매 금액과 일반 드랍의 예상 단가·판매대금·수수료·직접 분배금에 적용한다. 입력 방식과 저장 금액은 유지하며 빈 입력에는 표시하지 않고 잘못된 금액은 확인을 안내한다.

사냥에서 자동 생성된 **솔 에르다 조각**은 판매 날짜·수량·개당 판매 금액을 입력하면 총 판매 금액을 계산한다. 총액을 직접 입력하거나 수수료가 있었다면 실제 받은 금액으로 조정할 수 있다. 입력한 총액 전체가 수익이며 인원·분배 방식은 입력하지 않는다. 판매 목록에도 단가와 총 판매 금액을 표시한다. 단가로 나누어떨어지지 않는 총액은 직접 입력한 총액으로 보존한다. 예전에 수수료·다인 분배·직접 분배를 기록한 판매는 금액을 유지하기 위해 기존 수정 화면을 사용한다.

판매일, 판매 수량, 해당 수량 전체의 판매대금과 실제 수수료를 입력한다. 수수료율을 가정하지 않는다. 균등 분배는 `(전체 판매대금 - 전체 수수료) / 분배 인원`을 정수로 내림한다. 실제 분배가 다르면 내 분배금을 직접 입력하며 수수료 차감 후 전체 금액을 초과할 수 없다. 인원은 1~6명이다. 보스 드랍의 기본 인원은 획득 묶음 생성 당시 보스 기록을 사용하고, 판매마다 수정할 수 있다.

한 판매는 한 획득 묶음에 연결된다. 여러 회차 재고를 한 번에 판매한 경우 묶음별 수량과 대금을 나누어 입력한다. 판매 수량은 남은 수량을 넘을 수 없다. 판매 수정은 기존 자기 수량까지 다시 사용할 수 있다.

예: 10개 획득, 3개를 전체 1,001메소에 판매, 수수료 100메소, 3인 균등 분배 → 내 몫 300메소, 미판매 7개. 예상 단가 200메소라면 미판매 예상 가치는 1,400메소다.

## 실제 수익과 예상 가치

미판매 재고의 `남은 수량 × 예상 단가`는 참고값이며 장부에 수입을 생성하지 않는다. 판매 시 내 몫만 수입 하나를 생성한다. 0메소 판매도 판매 수량은 소비하지만 0금액 거래는 만들지 않는다. 예상 단가 변경은 과거 판매의 단가 스냅샷이나 실제 수익을 바꾸지 않는다. 판매 수정·취소는 연결 거래를 같이 수정·삭제한다.

사냥 회차의 순수익과 시간당 순수익은 직접 획득 메소 + 연결된 드랍 판매 수익으로 계산한다. 새 사냥 기록은 소모 비용을 입력하지 않고 0으로 저장한다. 과거 기록의 비용과 지출 거래는 보존하며 순수익에서 차감한다. 사냥 조회는 사냥 날짜 기준이고, 거래 내역·대시보드는 실제 판매일 기준이다. 시간이 0분인 사냥은 시간당 집계에서 제외한다. 보스 상단 요약은 결정석 기준이며 드랍 수익은 각 드랍 관리와 거래 장부에서 확인한다. 보스 드랍의 획득 기준일은 주차 시작일이며 실제 처치 날짜를 자동 추정하지 않는다.

사냥 시간은 새 입력 화면에서 30분이 기본값이며 다른 시간으로 변경할 수 있다. 코어 젬스톤은 기본 입력에서 숨기고 **추가 기록: 코어 젬스톤**을 선택했을 때 수량을 입력한다. 수량이 있는 기존 회차를 수정할 때에는 자동으로 선택한다. 수량이 0인 회차 목록에서는 젬스톤을 표시하지 않는다. 이미 판매한 수량보다 줄이는 변경은 기존 재고 보호 규칙으로 차단한다.

## 수정·삭제와 저장

- 판매된 수량보다 획득 수량을 줄일 수 없다. 판매를 먼저 수정·취소한다.
- 판매가 연결된 사냥은 캐릭터·사냥 날짜 변경과 삭제를 막는다. 판매 취소 후 변경할 수 있다.
- 판매가 연결된 보스 기록도 삭제를 막는다. 보스 클리어 체크 해제는 획득 묶음을 정리한 뒤 가능하다.
- 일반 획득 묶음은 판매를 모두 취소한 뒤 삭제한다. 사냥 조각·젬스톤 삭제는 회차 수량을 0으로 수정한다.
- 획득·판매 생성 요청은 UUID로 중복을 방지한다. 동일 UUID의 내용 변경은 충돌로 처리한다.
- 판매·거래·수량 집계 검증은 같은 트랜잭션으로 실행한다. 일부 저장 실패 시 전부 롤백한다. 안전한 정수 범위를 넘는 예상 가치·수익·시간당 계산도 저장을 거부한다.

4번 DB 마이그레이션은 기존 사냥의 조각·젬스톤 수량을 판매 가능한 재고로 연결하고, 기존 사냥·결정석 거래의 ID·날짜·금액·시각을 보존한다. 이미 판매했지만 기존 앱에 수량만 기록한 아이템은 실제 판매 기록을 직접 추가한다.
