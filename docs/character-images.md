# 캐릭터 외형 이미지

넥슨 기본 정보 API의 `character_image` URL을 캐릭터 프로필과 함께 저장한다. API 등록 또는 **API 정보 갱신**에서 채워지므로, 이미 등록한 캐릭터는 한 번 갱신한다. 이미지 표시만을 위해 기본 정보 API를 화면마다 호출하지 않는다. 저장된 URL의 이미지를 넥슨 이미지 서버에서 읽으며, 별도의 API 키를 이미지 요청에 붙이지 않는다.

캐릭터 관리에서는 160px, 주간 보스 그룹·사냥 회차·대시보드·지출 내역에서는 48px 크기로 표시한다. 기록의 캐릭터 ID로 현재 프로필을 찾아 연결하며, 예전 기록의 닉네임·서버 스냅샷은 유지한다. 따라서 이미지는 과거 시점의 외형이 아니라 가장 최근에 갱신한 외형이다. 기본 select 입력의 선택지는 텍스트를 유지한다.

수동 등록, 이미지 없는 프로필, 만료된 프로필, 이미지 로딩 실패에는 닉네임 첫 글자를 표시한다. 네트워크 없이 이미지 표시를 보장하는 로컬 이미지 복사본은 만들지 않는다. 이미지 URL 또는 프로필 갱신 시각이 바뀌면 다시 표시를 시도한다. 프로필의 기존 30일 만료 처리 및 API 연결 해제는 이미지 URL도 지운다.

`https://open.api.nexon.com/static/maplestory/character/look/` 경로만 허용한다. 외부 사이트·다른 API 경로·자격 증명 포함 URL은 표시하지 않는다. CSP에서도 이미지 서버 경로만 허용하며 참조 페이지 정보는 전송하지 않는다. 메인 프로세스에서 PNG를 읽고 원본 캔버스의 중심을 유지한 정사각형으로 표시한다. 300×300 원본은 기본 200×200 중앙 영역을 공유하므로 무기의 방향에 따라 몸 위치나 배율이 달라지지 않는다. 큰 모자·무기가 영역을 벗어나면 중심을 유지한 채 표시 범위를 대칭으로 확장해 외형 전체를 보존한다. 정사각형이 아닌 원본은 전체 이미지를 사용한다. 화면은 조정된 PNG 데이터만 받아 칸 안에 맞춘다. 같은 프로필의 요청은 합치고 결과를 메모리에 5분간 보관하며, 프로필 갱신 시 다시 읽는다. 디스크에 이미지 파일을 저장하지 않는다. 이미지 요청은 10초, 2MiB로 제한하고 리다이렉트를 허용하지 않는다.

DB 마이그레이션 11은 `characters.nexon_image_url`을 NULL 허용 필드로 추가한다. 마이그레이션 12는 이미 적용된 11번 DB의 이미지와 기록을 유지하면서 URL 제한을 8,192자로 확장한다. 실제 넥슨 이미지 URL은 1,000자를 넘을 수 있다. 백업에서도 같은 길이를 지원하고, DB 7~10번 백업에는 이미지 URL을 NULL로 보완하며 11번 백업은 그대로 읽는다. 새 형식의 장부를 개발 버전으로 연 뒤에는 구형 설치 앱이 지원하지 않을 수 있으므로 수정된 v0.2.1 이상을 사용한다.

검증: 등록·갱신·연결 해제·30일 만료, 이미지 없는 API 응답, 긴 이미지 URL 백업·복원, 이전 7~10번 백업 호환, 11번 DB 업그레이드와 허용되지 않은 URL을 테스트했다. 별도 임시 장부의 Electron 앱에서는 가상 이미지 응답으로 정상 로딩·CSP·실패 시 대체 표시와 각 화면의 연결을 확인했다. 실제 넥슨 응답의 1,096자 URL도 임시 장부에서 API 등록·저장·화면 로딩까지 확인했다.

추가 검증: 원본 중심 유지·공통 배율·큰 장비의 표시 범위 확장·요청 중복 방지·프로필 갱신 후 재요청·실패 대체 표시·파일 크기 제한을 포함해 343개 테스트가 통과했다. 실제 저장된 이미지 URL을 읽기 전용으로 가져와 별도의 임시 Electron 장부에서 6개 캐릭터 모두 200×200 공통 영역을 사용하고 160px 이미지 칸에 표시되는 것을 확인했다.

캐릭터 카드에서는 이미지 오른쪽에 닉네임·서버 배지·직업·레벨·길드·API 연결 및 갱신 시각을 모아 표시한다. 좁은 창에서는 정보가 자연스럽게 아래로 줄바꿈된다. 메모와 관리 버튼은 아래에 유지한다. 임시 Electron 장부에서 우측 배치, 수동 등록, 미갱신 프로필과 1024px 창의 넘침 없는 배치를 확인했다.
