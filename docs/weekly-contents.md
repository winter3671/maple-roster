# 이번 주 콘텐츠

주간 콘텐츠 메뉴에서 등록 캐릭터의 지하수로·플래그 레이스 점수와 참여 기록을 확인한다. 전체 새로고침은 숨긴 캐릭터까지 포함한 API 연결 캐릭터를 순차 조회한다. 표는 기본적으로 숨긴 캐릭터를 제외하며, 숨김 포함으로 표시할 수 있다. 수동 캐릭터에는 API 연결 필요를 표시한다.

한국 시간 목요일 00시부터 다음 목요일 00시 직전까지를 한 주차로 계산한다. 오늘의 실시간 스케줄러 주간 수행 상태를 사용하며, 7일을 각각 조회하거나 수행 수치를 합산하지 않는다. 조회가 주차 경계를 넘으면 이전 주 데이터를 새 주차에 저장하지 않는다. 화면을 열어 둔 경우 1분마다 로컬 상태를 다시 읽어 주차 전환을 반영한다. 이 확인은 넥슨 API를 호출하지 않는다.

지하수로·플래그의 수행 수치가 양수이면 O와 점수를 표시한다. 지하수로는 점수가 0이거나 해당 항목이 없으면 빨간색 `X · 참여 기록 없음`으로 표시한다. 플래그는 0이면 참여 기록 없음, 항목이 없으면 확인 불가로 표시한다. 응답 실패는 두 항목 모두 확인 불가로 구분한다. `registration_flag`는 게임 스케줄러 등록 여부이므로 참여 여부로 사용하지 않는다.

에픽 던전은 지원하지 않는다. 실제 API에서 등록된 서로 다른 캐릭터에 동일한 수치를 반환하여 수행한 캐릭터를 식별할 수 없었으므로, 캐릭터별 참여로 해석하거나 표시하지 않는다.

결과는 현재 주차의 메모리 캐시에만 보관한다. 화면 이동 후 다시 돌아와도 유지되며, 앱 재실행·주차 변경 후에는 다시 조회한다. 장기 이력이나 장부 수익을 만들지 않으며 기존 DB·백업 형식을 변경하지 않는다. API 연결 변경·해제·캐릭터 삭제 시 다른 캐릭터의 결과를 재사용하지 않는다. 개별 오류는 다음 캐릭터 조회를 막지 않으며, API 키 오류·호출 제한·네트워크 오류는 후속 요청을 멈추고 미조회 이유를 표시한다.
