# 주간 콘텐츠

주간 콘텐츠 메뉴에서 모든 등록 캐릭터의 지하수로·플래그 레이스 점수와 참여 기록을 확인한다. **전체 새로고침**은 API 연결 캐릭터를 순차 조회한다. 수동 캐릭터에는 API 연결 필요를 표시한다.

한국 시간 목요일 00시부터 다음 목요일 00시 직전까지를 한 주차로 계산한다. 오늘의 실시간 스케줄러 주간 수행 상태를 사용하며, 일별 수치를 합산하지 않는다. 조회가 주차 경계를 넘으면 이전 주 데이터를 새 주차에 저장하지 않는다. 화면을 열어 둔 경우 1분마다 로컬 상태를 다시 읽어 주차 전환을 반영한다. 이 확인은 넥슨 API를 호출하지 않는다.

수행 수치가 양수이면 O와 점수를 표시한다. 지하수로 점수가 0이거나 해당 항목이 없으면 빨간색 **X · 참여 기록 없음**으로 표시한다. 플래그는 0이면 참여 기록 없음, 항목이 없으면 확인 불가로 표시한다. 미조회·API 오류는 미참여로 단정하지 않는다. registration_flag는 스케줄러 등록 여부이므로 참여 여부로 사용하지 않는다.

조회에 성공한 점수와 마지막 확인 시각은 SQLite에 저장해 화면 이동과 앱 재실행 후에도 유지한다. **이번 주 / 지난주** 선택으로 두 주차를 확인한다. 지난주는 당시 저장한 결과만 표시하며 과거 API 조회를 요청하지 않는다. 이번 주의 최신 점수는 전체 새로고침으로 확인한다. 갱신에 실패하면 마지막 성공 결과를 유지하고 오류를 함께 표시한다.

앱 실행과 주간 콘텐츠 조회 시 이번 주·지난주를 제외한 기록을 자동 삭제한다. 목요일에는 이전 결과가 지난주로 이동하고 이번 주는 미조회로 시작한다. 캐릭터 삭제 시 해당 기록도 삭제한다. API 연결 변경·해제 시 다른 OCID의 기록을 표시하지 않는다. 단기 API 캐시는 JSON 장부 백업에 포함하지 않으므로 장부 복원 후에는 다시 조회한다.

개별 오류는 다음 캐릭터 조회를 막지 않으며, API 키 오류·호출 제한·네트워크 오류는 후속 요청을 멈추고 미조회 이유를 표시한다. 에픽 던전은 API가 실제 수행 캐릭터를 구분하지 못하므로 지원하지 않는다.
