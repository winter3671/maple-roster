# 보스 아이콘

사용자가 제공한 게임 길라잡이 캡처에서 아이콘 영역을 원본 크기로 잘라 로컬 PNG로 보관한다. 웹사이트나 이미지 서버를 앱 실행 중 조회하지 않는다. `src/frontend/assets/bosses`에 이미지 54개를 포함하며 `src/shared/boss-icon-manifest.ts`에 보스·난이도·파일명·원본 캡처 이름·절단 좌표와 크기를 기록한다.

주간 보스 카탈로그의 24종·52개 난이도 조합과 월간 검은 마법사 하드·익스트림 2개에 대응한다. 월간 아이콘도 기존에 제공된 길라잡이 원본 캡처에서 가져온다. 이미지는 원본 품질을 유지하며 확대 보정이나 생성형 이미지 수정을 하지 않는다.

하드 스우는 커서에 가리지 않은 추가 캡처에서 HARD 표기까지 포함해 원본 아이콘을 사용한다. 이전의 별도 한글 난이도 배지는 제거했다. 칼로스와 최초의 대적자는 최초 이미지 추출 시 보스 연결이 서로 반대였다. 이를 난이도 표기 차이로 잘못 판단했던 별도 배지를 제거하고, 두 보스의 이지·노멀·카오스 또는 하드·익스트림 총 8개 아이콘을 올바른 보스로 연결했다. 추가 캡처에서 첫 줄 세 번째 HARD 아이콘은 하드 최초의 대적자, 둘째 줄 네 번째 CHAOS 아이콘은 카오스 칼로스다. 모든 아이콘은 게임 원본의 난이도 표기를 그대로 사용하며 현재 `badge`는 모두 `false`다. [공식 보스 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/459)의 난이도 목록과 대조했다. 이미지 연결만 수정하며 보스 기록·API 이름·가격표·카탈로그·정렬 기준은 유지한다.

`BossIcon.tsx`는 Vite로 묶은 이미지 주소를 보스·난이도 조합으로 찾는다. 보스 장부에는 56px로 표시하며 작은 아이콘은 40px 표시를 지원한다. 이름·난이도·인원 텍스트도 유지한다. 기존 자유 입력 기록에 해당 이미지가 없거나 이미지 로딩에 실패하면 보스 이름 앞부분을 표시하고 기존 관리 기능을 유지한다.

카탈로그 대응·중복 파일·원본 크기·고아 이미지 검사를 테스트한다. Electron 임시 장부에서 주간 조합 52개와 프리셋 12개의 이미지가 로컬 파일로 로딩되는지 확인하고 보스 행의 화면도 검토했다.

원본은 사용자가 직접 제공한 게임 캡처이며 넥슨의 게임 이미지다. 공개 배포 전에 이미지 이용 조건을 확인한다.
