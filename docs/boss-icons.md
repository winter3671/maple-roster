# 보스 아이콘

사용자가 제공한 게임 길라잡이 캡처 5장에서 아이콘 영역을 원본 크기로 잘라 로컬 PNG로 보관한다. 웹사이트나 이미지 서버를 앱 실행 중 조회하지 않는다. `src/frontend/assets/bosses`에 이미지 54개를 포함하며 `src/shared/boss-icon-manifest.ts`에 보스·난이도·파일명·원본 캡처 이름·절단 좌표와 크기를 기록한다.

주간 보스 카탈로그의 24종·52개 난이도 조합과 월간 검은 마법사 하드·익스트림 2개에 대응한다. 월간 아이콘도 기존에 제공된 길라잡이 원본 캡처에서 가져온다. 이미지는 원본 품질을 유지하며 확대 보정이나 생성형 이미지 수정을 하지 않는다.

하드 스우는 원본에서 마우스가 가려 깨끗한 노멀 스우의 초상화 영역을 재사용하고 하드 배지를 별도로 표시한다. 캡처에서 HARD인 칼로스와 CHAOS인 최초의 대적자는 앱 카탈로그의 카오스 칼로스·하드 대적자와 표기가 다르므로 원본 난이도 영역을 제외하고 앱 난이도 배지를 표시한다. 이는 표시 보완이며 API 이름·가격표·카탈로그·정렬 기준을 바꾸지 않는다. 해당 3개는 매니페스트의 `badge: true`로 구분한다. 나머지는 캡처의 난이도 표기를 그대로 사용한다.

`BossIcon.tsx`는 Vite로 묶은 이미지 주소를 보스·난이도 조합으로 찾는다. 보스 장부에는 56px, 공용 프리셋·캐릭터 구성과 구성 편집에는 40px로 표시한다. 이름·난이도·인원 텍스트도 유지한다. 기존 자유 입력 기록에 해당 이미지가 없거나 이미지 로딩에 실패하면 보스 이름 앞부분을 표시하고 기존 관리 기능을 유지한다.

카탈로그 대응·중복 파일·원본 크기·고아 이미지 검사를 테스트한다. Electron 임시 장부에서 주간 조합 52개와 프리셋 12개의 이미지가 로컬 파일로 로딩되는지 확인하고 보스 행의 화면도 검토했다.

원본은 사용자가 직접 제공한 게임 캡처이며 넥슨의 게임 이미지다. 공개 배포 전에 이미지 이용 조건을 확인한다.
