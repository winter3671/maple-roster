# 결정석 가격 이력 관리

**설정 → 결정석 가격표 관리**에서 보스·난이도를 선택하면 앱 기본 가격표와 수동 등록 이력을 볼 수 있습니다. 가격은 파티 분배 전 **1인 클리어 기준 전체 결정석 가격**입니다. 앱은 이 값을 클리어 인원으로 나눈 뒤 1메소 미만을 버립니다.

## 가격 등록과 수정

보스·난이도, 적용일, 가격, 확인일, 출처를 입력하고 **가격표 저장**을 누릅니다. 출처에는 공지 URL이나 게임 안에서 직접 확인한 위치를 적을 수 있습니다. 확인일은 오늘까지, 적용일은 향후 공지가 확정된 경우 미래 날짜도 등록할 수 있습니다. 가격은 1메소 이상의 안전한 정수입니다.

같은 보스·난이도·적용일로 저장하면 기존 수동 이력을 교체합니다. 적용일이 다르면 새 이력이 추가됩니다. 수동 행의 **불러오기**로 입력값을 가져와 수정할 수 있으며, 같은 키로 저장해야 기존 행을 교체합니다. 보스·난이도·적용일을 바꿔 저장하면 별도 이력이 생깁니다.

**삭제**는 확인 후 해당 수동 이력만 제거합니다. 앱 기본 가격표는 삭제하지 않습니다. 수동 가격표는 최대 5,000개까지 저장합니다.

## 적용 규칙

조회 기준일 이하의 이력 중 가장 최근 적용일을 선택합니다. 같은 날짜에 앱 기본과 수동 이력이 모두 있으면 수동 가격을 우선합니다. 미래 이력은 적용일 전에는 사용하지 않습니다. 기본 가격표가 나중 날짜에 있으면 그 기본 가격이 더 오래된 수동 가격보다 우선합니다.

- 프리셋 저장·묶음 할당: 오늘(KST)의 가격
- 새 주간 보스 기록과 API 자동 추가: 목요일 주차 시작일의 가격
- 기존 기록의 메모·인원 수정과 반복 조회·주차 재생성: 저장된 가격 유지
- 기존 기록의 보스·난이도 변경: 해당 주차의 변경된 보스 가격

예를 들어 10월 8일 스우 노멀을 10,000,000메소로 등록하면 10월 8일 이후 주차의 새 기록에 적용됩니다. 이미 8,350,000메소로 저장한 기록은 그대로 유지됩니다. 수동 가격을 수정하거나 삭제해도 과거 장부를 다시 계산하지 않습니다. 새 주차 생성은 프리셋에 저장된 옛 가격이 아닌 해당 주차의 가격표를 사용합니다.

설정에서 저장하면 프론트엔드 예상 금액과 백엔드 계산에 즉시 반영합니다. 가격표 변경 전 조회한 API 미리보기는 무효화하며 다시 조회해야 합니다. 자동으로 공식 사이트를 조회하거나 가격을 갱신하지 않습니다. 확인일은 입력자가 확인한 날짜이며 앱의 공식 검증 인증이 아닙니다.

## 기본 가격과 보관

기본 이력은 기존에 확인한 52개 보스·난이도의 가격을 보존하며 적용일·확인일·출처를 표시합니다. 출처에는 [6월 본 서버 공지](https://maplestory.nexon.com/News/Update/806), [9월 본 서버 공지](https://maplestory.nexon.com/News/Update/813)와 기존 교차 확인 자료를 구분해 기록합니다. 기본 확인일은 2026-10-08입니다.

수동 이력은 DB의 `crystal_price_history` 테이블에 저장하고 JSON 백업에 포함합니다. DB 버전은 9입니다. 이전 7·8번 DB는 장부를 유지하면서 새 테이블을 추가합니다. 7·8번 JSON 백업도 복원할 수 있지만 수동 가격표가 없으므로 전체 복원 시 현재 수동 이력은 비워집니다. 복원 직전 안전 백업에는 현재 가격표도 보관됩니다. 새 9번 백업은 이전 앱에서 복원할 수 없습니다.

보스 표시 순서는 이번 변경에서 수동 가격과 연결하지 않았습니다. 정렬 기준 분리는 별도 개선 단계입니다.
