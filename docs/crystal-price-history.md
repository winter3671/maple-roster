# 결정석 가격표 갱신

결정석 가격은 앱에 포함된 가격표로 자동 계산한다. 설정에서는 확인일과 갱신 방식을 안내하며 수동 가격 등록·수정·삭제 기능은 제공하지 않는다. 수동 가격 저장·삭제 IPC도 제거했다.

## 공지 반영과 배포

게임 공지에서 본 서버 결정석 가격 변경을 확인한 뒤 `src/shared/crystal-prices.ts`의 가격 이력을 갱신한다. 보스·난이도별 1인 기준 가격, 적용일, 확인일, 출처를 함께 보관한다. 과거 적용일의 이력을 덮어쓰지 않고 새 이력을 추가한다. 현재 이력에는 기존에 교차 확인한 자료도 포함되어 있으므로 신규 변경 시 공지에 명시된 가격을 검증한다.

미래 변경도 적용일 전에는 사용하지 않는다. 프론트엔드 예상 금액과 백엔드 신규 기록·API 자동 등록은 같은 기본 이력을 사용한다. 주차 시작일 이하에서 가장 최근의 가격을 선택하고 인원으로 나눈 뒤 1메소 미만을 버린다. 가격을 갱신한 후 가격·인원 계산 테스트와 앱 빌드를 확인하고 릴리스 노트에 변경을 작성해 새 버전으로 배포한다. 공지를 자동 조회하는 기능은 아니다.

## 기존 장부 보존

이미 저장한 보스 기록의 가격과 결정석 수익은 재계산하지 않는다. 메모·인원 수정은 저장된 가격을 사용하고 보스·난이도를 바꾸면 해당 주차 기본 가격을 사용한다.

이전 수동 이력과 DB 테이블은 백업·복원 호환을 위해 유지한다. 이전 이력을 복원해도 새 보스 계산에는 적용하지 않는다. 이전 가격 관리 서비스의 테스트는 이 호환 데이터를 검증하며 실제 앱에서는 수정 기능을 노출하지 않는다.

보스 표시 순서는 별도의 `src/shared/boss-display-order.ts`에서 관리하며 가격 변경으로 표시 순서가 달라지지 않는다.
