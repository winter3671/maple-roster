# 강화 지출 가져오기

거래 내역의 **강화 지출 가져오기**에서 날짜를 선택해 **강화 이력 조회**를 누른다. 현재 활성 API 계정의 잠재능력 재설정 이력을 하루 단위로 가져오며, 그 계정의 캐릭터 목록과 앱에 API로 등록된 캐릭터를 대조한다. 등록하지 않은 캐릭터와 현재 계정에 속하지 않는 캐릭터는 포함하지 않는다. 닉네임이 변경되어 과거 이름과 일치하지 않는 이력도 제외한다. 메소 잠재능력·에디셔널 재설정 및 지원하는 큐브의 사용 수수료를 함께 조회한다. 스타포스·소울 잠재능력·큐브 구매 가격은 포함하지 않는다.

조회만으로는 지출이 생성되지 않는다. 캐릭터 이름과 재설정 종류별로 횟수·대표 장비·합계 금액을 표시한다. 잠재능력 API는 OCID와 월드를 반환하지 않으므로, 같은 계정에 같은 이름이 여러 월드에 있으면 자동 선택하지 않는다. 해당 날짜에 한 캐릭터에서만 강화했다는 사실을 사용자가 알고 있을 때만 그 캐릭터를 선택한다. API만으로 각 월드의 사용량을 구분할 수 없으므로, 여러 월드에서 강화했거나 구분할 수 없는 묶음은 선택하지 않고 수동으로 나누어 기록한다.

## 비용 계산과 확인

API에는 실제 사용 메소가 없다. 메소 재설정은 장비 레벨과 **재설정 이전 첫 번째 옵션의 등급**으로 기본 비용을 계산한다. 등급 상승 후의 `potential_option_grade`를 사용하지 않는다. 기본 비용표의 근거는 다음 공식 본 서버 공지다.

- [2024-01-25 잠재능력 재설정 도입 및 비용표](https://maplestory.nexon.com/News/Update/737)
- [2024-06-20 에디셔널 잠재능력 재설정 도입 및 비용표](https://maplestory.nexon.com/News/Update/746)
- [넥슨 공식 확률 이력 API 명세](https://openapi.nexon.com/static/script/maplestory/XzReHw-91Vrd5NTyC62EdlYG74xXpdBnbhQdW5aUlKo.yaml)

기본 비용은 실결제 금액을 보증하지 않는다. 이벤트·할인 등의 차이가 있으면 사용자가 확인한 총액으로 수정한다. 레벨·이전 등급이 없거나 지원 범위를 벗어나면 금액을 비워 두고 자동 선택하지 않는다. 금액을 확인할 수 없다면 반영하지 않는다. 큐브를 무료로 얻었거나 캐시로 샀더라도 **사용할 때 별도로 차감되는 메소 수수료**는 가져오기 대상이다. 큐브 아이템 자체의 구매 가격을 임의로 메소 지출로 환산하지 않는다.

선택한 항목의 금액·캐릭터를 확인하고 **실제 비용과 기존 수동 지출의 중복 여부를 확인했습니다**를 체크한 뒤 반영한다. 한 묶음은 해당 날짜의 `강화` 지출 하나로 저장하며, 대시보드와 거래 내역에 같은 금액을 반영한다. 저장 후 창을 닫는다. 가져온 지출도 기존 지출 수정·삭제 기능을 사용할 수 있다.

## 페이지 조회와 중복 방지

- 최근 2년 이내의 날짜를 조회한다. 공식 명세 기준 재설정 이력은 최대 30분 지연될 수 있다.
- 각 API별로 한 페이지 1,000건, 최대 20페이지를 순서대로 읽는다. 두 API 중 하나라도 실패하면 미리보기를 반영하지 않는다. 반복 커서·한도 초과·요청 날짜 불일치·조회 실패 시 부분 결과를 반영하지 않는다. 커서 조회에는 날짜를 중복 전송하지 않는다.
- 미리보기는 15분간 유효하며 다시 조회하거나 API 계정·캐릭터 연결이 바뀌면 기존 결과로 반영하지 않는다.
- 기존 메소 재설정 이력의 해시는 유지하고, 큐브 이력은 `cube:` 네임스페이스를 붙여 다른 API와의 ID 충돌을 방지한다. 원본 이력 ID는 SHA-256 해시로 저장하고, 화면·메모·백업에 원문을 남기지 않는다. API 키 지문은 계정 변경 감지를 위해 메모리에서만 사용한다.
- 한 번 반영한 해시는 지출 수정·삭제 후에도 유지한다. 삭제한 지출을 API로 다시 불러와 되살리지 않는다. 금액을 바로잡으려면 기존 지출을 수정하거나 수동으로 다시 기록한다.
- 선택하지 않은 항목이나 이후 추가된 이력은 다음 조회에서 반영할 수 있다. 기존 수동 지출과 API 이력의 동일성을 자동 판별하지 않으므로 사용자 확인이 필요하다.
- 선택한 여러 묶음의 지출·연결 거래·이력 해시는 하나의 트랜잭션으로 저장한다. 중간 저장이 실패하면 모두 롤백한다.
- DB 마이그레이션 18은 `enhancement_imports`를 추가한다. 새 백업은 중복 방지 해시도 보관하며, 17 이하 백업은 빈 해시 목록으로 호환한다.

검증은 모의 넥슨 응답과 임시 SQLite 장부로 수행한다. 실제 사용자 키나 강화 이력을 테스트에 사용하지 않는다.

## 큐브 사용 수수료

공식 `history/cube` 응답의 `cube_type`, `target_item`, `item_level`로 큐브 종류·대상 장비·기본 장비 레벨을 확인한다. 메멘토 이름의 `(200제)` 등은 큐브의 사용 제한이며 실제 대상 장비의 레벨 대신 사용하지 않는다. 큐브 수수료는 잠재능력 등급별 수천만 메소 재설정 비용과 구분한다.

현재 지원 이름은 브론즈 에디셔널·에디셔널·화이트 에디셔널·실버·골드·레드·블랙·장인·명장·수상한·수상한 에디셔널 큐브다. 메멘토·카르마·이벤트 링 전용·대적자의 접두사 및 제수 제한 표기를 구분해 인식한다. 알 수 없는 새 큐브나 펄스 인핸서 등 특수 재화에는 수수료를 임의 적용하지 않고 제외 건수로 표시한다.

121~300레벨 장비는 기본 감정 수수료 추정식 `장비 기본 레벨² × 20`을 사용한다. 사용자에게 제공받은 인게임 확인값은 **200제 장비 / 메멘토 브론즈 에디셔널 큐브 / 1회 800,000메소**이며 이 식과 일치한다. 이 계산식을 넥슨 API가 반환하거나 공식 문서에서 직접 확인한 수수료라고 표시하지 않는다. 다른 레벨·예외는 추정치이므로 실제 게임의 사용 수수료와 대조해 반영한다.

공식 [잠재능력 가이드](https://gi.maplestory.nexon.com/Guide/GameInformation/ItemEnhancement/Potential)는 30레벨 이하 장비 무료 감정을 안내하며, [성향 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/382)는 통찰력에 따른 30/70/120레벨 이하 무료 감정 단계를 설명한다. 사용자 지정 집계 기준으로 1~120레벨 장비의 큐브 수수료는 모두 기본 0메소로 표시하고, 다른 장비와 함께 합산할 때도 0으로 계산한다. 실제 비용이 발생했다면 사용자가 해당 묶음의 총액에 추가한다. 0메소뿐인 묶음은 기본 선택하지 않으며, 비용을 입력한 뒤 선택하여 반영할 수 있다. 이 기준은 게임의 실제 수수료가 항상 0이라는 뜻은 아니다. 장비 레벨을 모르는 경우도 자동 계산하지 않는다.

화면의 **장비 레벨·1회 비용 확인**을 펼치면 장비명·레벨·사용 횟수·1회 비용·누적 금액을 볼 수 있다. 같은 큐브·장비·레벨은 등급이 바뀌어도 사용 횟수를 묶는다. 메소 재설정과 큐브 사용료는 별도 항목으로 확인·반영하며, 양쪽 모두 수정 가능한 총액과 기존 수동 지출 중복 확인 절차를 유지한다.
