# 30분 사냥 빠른 기록

사냥 장부는 기본적으로 **빠른 기록** 모드를 연다. 캐릭터를 선택한 뒤 직접 획득한 메소와 솔 에르다 조각 수량만 입력하고 **30분 기록 저장**을 누른다. 조각이 없으면 0을 입력한다. Enter로도 저장할 수 있다.

저장할 때 한국 시간 기준 오늘 날짜를 사용하고 시간은 30분으로 고정한다. 메모는 빈 값, 코어 젬스톤·소모 비용은 0으로 저장한다. 사냥터 입력은 추가하지 않는다. 다른 날짜·시간이나 추가 항목이 필요하면 **상세 기록**으로 전환한다. 두 모드를 전환할 때 각 입력값은 유지하지만 서로 복사하지 않는다. 화면을 벗어난 미저장 입력은 유지하지 않는다.

성공 후 메소·조각 입력은 비워지고 캐릭터 선택은 유지한다. 메소 입력에 포커스를 돌려 연속 기록을 돕는다. 실패하면 입력을 유지하고 기존 저장 요청의 중복 방지 처리를 사용한다. 같은 수치로 다음 회차를 기록하면 별도의 30분 회차로 저장한다. 금액 아래에는 억·만 단위 안내를 표시한다.

마지막으로 성공한 빠른 기록의 캐릭터 ID는 이 기기의 화면 설정에 저장한다. 재실행 시 해당 캐릭터를 다시 선택하고, 삭제된 캐릭터이면 첫 캐릭터를 선택한다. 등록된 캐릭터가 없으면 저장을 막고 등록을 안내한다. 이 선택 설정은 JSON 장부 백업에 포함하지 않으며 설정을 저장하지 못해도 사냥 기록은 저장할 수 있다.

별도 장부를 만들지 않고 기존 사냥 저장 기능을 사용한다. 따라서 회차·시간·메소·조각 수량 통계, 획득 아이템, 거래 내역, 대시보드와 백업에 기존 회차와 동일하게 반영된다. 솔 에르다 조각은 획득 수량을 보관하고 실제 판매를 기록한 후 수익에 포함한다. 조회 기간 밖에 저장한 회차는 해당 기간을 조회해 확인한다.

격리 Electron 화면에서 입력 검증과 실패 시 입력 유지, 연속 저장·Enter 저장, 총 60분 통계, 거래·조각 재고 연결, 상세 모드 전환, 재실행 후 기록·캐릭터 선택 유지를 확인했다.

## 사냥 수익과 조각 요약

조회 조건 아래에는 순수 메소 수익(직접 획득 메소), 솔 에르다 조각 획득량·미판매 수량, 판매 수량, 실제 판매 수익을 표시한다. 조회 기간 순수익 요약은 제거한다. 총 사냥 수입은 획득 메소와 모든 사냥 드랍 판매 수익을 합산하며 시간당 획득 메소는 판매 수익과 과거 비용을 제외한다.

기간·캐릭터 조건에 맞는 사냥 회차의 획득 수량과 연결된 판매를 집계한다. 기간 밖에 판매한 조각도 해당 회차의 판매에 포함하며, 실제 판매일 기준인 대시보드·거래 내역과 구분한다. 젬스톤 판매는 조각 판매 수익에 포함하지 않고 전체 사냥 수입에는 포함한다. 부분 판매·수정·취소를 반영하고 재고와 판매 수익을 중복 집계하지 않는다. 기존 회차와 판매·과거 비용 기록은 보존한다.
