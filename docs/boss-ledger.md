# 보스 진행 및 주간·월간 기록

## 보스 장부 내부 화면

왼쪽 메뉴는 **보스 장부** 하나이며 상단의 세 버튼으로 아래 화면을 전환한다.

- **보스 진행도 및 정산**: 주차와 월을 따로 선택해 클리어 진행, 남은 보스 예상 수익, 이 주차 결정 수익, 이달 결정 수익을 확인한다. 남은 예상 수익은 등록된 미클리어 기록만 계산하며 아직 등록하지 않은 보스를 추정하지 않는다.
- **주간 보스 기록**: 목요일 00시(KST) 기준 주차별 보스 기록과 API 조회·드랍 관리를 제공한다.
- **월간 보스 기록**: 매월 1일 00시(KST)부터 말일까지 검은 마법사 하드·익스트림 기록을 관리한다. 난이도를 합쳐 캐릭터당 월 1개만 등록하며 인원은 1~6명이다. API 신규 기록은 1인 기준이므로 다인 파티는 수정한다. 이전 달 기록은 보존하며 새 달에 클리어를 복사하지 않는다.

월간 클리어도 결정 수익과 드랍 판매가 거래 내역·대시보드에 반영된다. 현재 월 수익일은 확인한 날, 과거 월은 월초이며 기간 시작일~오늘 사이로 수정할 수 있다. 월별 가격은 월초 적용 가격을 사용한다. 검은 마법사 가격은 [공식 공지](https://maplestory.nexon.com/News/Update/813)의 2026-10-01 적용일에 따라 하드 465,000,000 / 익스트림 5,680,000,000 메소다.

DB 16번 전환은 기존 보스 기록을 주간으로 유지하고 월간 구분만 추가한다. 기존 수익·드랍·반영일을 변경하지 않는다. 백업에는 두 종류를 함께 포함한다.

## 사용 흐름

1. 캐릭터를 등록한다.
2. 주차를 선택하고 **API 클리어 일괄 확인**으로 완료 보스와 수익을 자동 등록한다.
3. API 미연결 캐릭터나 수동 기록은 **+ 보스 추가**로 등록한다.
4. 보스를 잡았으면 **클리어**를 체크한다. `floor(1인 기준 결정 가격 / 클리어 인원)`이 바로 장부 수입으로 반영된다. 별도의 판매·미판매 상태나 판매 확정 단계는 없다.
5. 목록은 **서버 → 캐릭터 → 보스**로 묶는다. 보스명·난이도·인원을 누르면 수정 화면이 열린다. 보스·난이도·인원·메모·수익 반영일을 수정할 수 있고 결정 수익도 자동 갱신된다.
6. 체크를 해제하면 해당 결정 수입이 취소된다. 드랍 아이템 판매는 **드랍 관리**에서 별도로 기록한다.
7. 캐릭터 제목 옆 **+ 보스 추가**로 해당 주차에 보스를 추가할 수 있다. 같은 캐릭터·주차에는 난이도가 달라도 같은 보스를 중복 등록하지 않으며 최대 12개로 구성한다. 이미 12개이면 추가 버튼은 비활성화한다.
8. 행 오른쪽의 빨간 **×**를 누르고 확인하면 해당 주차 기록을 삭제한다. 목록의 결정 내 몫에는 금액만 표시한다.

캐릭터 안의 보스 행은 `src/shared/boss-display-order.ts`의 보스·난이도별 표시 순서로 정렬한다. 기존 진행 순서를 별도 데이터로 고정한 앱 표시 기준이며 공식 전투 난이도 순위를 의미하지 않는다. 정렬할 때 가격표를 조회하지 않으므로 기본·수동 가격 이력, 과거 주차의 저장 가격과 분배 인원·내 몫에 영향을 받지 않는다. 익세노흉 구성에서는 익스트림 스우 → 노멀 찬란한 흉성이 마지막에 온다. 정렬표에 없는 기존 이름·난이도는 알려진 조합 뒤에 유지하며 카탈로그의 보스 순서와 이름·난이도로 일관되게 정렬한다. 수정·추가 후에도 같은 기준으로 정렬한다. 새 보스·난이도를 카탈로그에 추가할 때에는 표시 순서에도 함께 추가한다.

## 주차·금액·날짜

주차는 KST 목요일 0시부터 수요일까지다. API 조회 또는 수동 추가로 주차의 보스·난이도·인원과 월드를 저장하고, 해당 주차의 결정 가격을 적용한다. 반복 API 확인은 기존 기록·인원·수익을 보존한다. 미래 주차 등록은 막는다.

현재 주차의 새 클리어는 오늘(KST)을 수익 반영일로 사용한다. 과거 주차를 뒤늦게 체크하면 주차 시작일로 기록한다. 실제 처치 시간을 자동 조회하지 않는다.

클리어한 보스의 **반영 수익** 아래에 날짜를 표시한다. 날짜를 누르면 **결정 수익 반영일 수정** 창에서 날짜만 변경할 수 있다. 주차 시작일~오늘 범위에서 선택하며 해당 주차가 끝난 뒤의 날짜도 허용한다. 원래 보스 주차·금액·인원·인원 확인 상태·메모는 유지하고 거래 내역과 대시보드의 집계 날짜만 바뀐다. 기록 수정 화면에서도 날짜를 변경할 수 있다. 수정 창을 연 뒤 다른 작업으로 반영일이 바뀌면 덮어쓰지 않고 새로고침을 안내한다.

진행·수익 요약은 보스 장부 안의 **보스 진행도 및 정산** 화면에 표시한다. 거래 내역·대시보드는 수익 반영일 기준이므로 월을 넘겨 날짜를 수정하면 집계 월도 바뀐다. 남은 예상 수익은 장부 수입에 포함하지 않는다. 0 메소 클리어는 완료 상태와 내부 수익 기록만 남기고 0 메소 거래를 만들지 않는다.

## 수정·취소와 보존

- 체크 반복 저장은 금액·날짜·거래 ID를 유지하고 중복 수입을 만들지 않는다.
- 난이도·인원 변경은 주차의 가격표와 저장 가격으로 수익을 다시 계산한다. 수익 날짜와 거래 ID는 유지한다.
- 보스를 교체하면 해당 주차의 새 보스 가격으로 재계산한다. 클리어 여부·수익 날짜·거래 ID는 유지하며, 드랍 묶음이 연결된 기록은 먼저 드랍을 정리해야 보스를 교체할 수 있다.
- 주차 화면에서 추가·교체·삭제한 내용은 해당 주차에만 반영한다.
- 클리어·수익·장부 저장은 한 트랜잭션이다. 장부 오류가 있으면 클리어와 내용 수정도 되돌린다.
- 체크 해제는 클리어와 결정 수입을 함께 취소한다. 획득한 드랍 묶음이 있으면 먼저 정리해야 체크를 해제할 수 있다.
- 기록 삭제는 해당 주차와 연결 결정 수입을 함께 삭제한다. 드랍 판매 이력이 있으면 먼저 판매를 취소해야 한다.
- 보스 묶음·캐릭터별 기본 구성 기능은 제공하지 않는다. 기존 주차 기록은 유지한다.

## 기존 데이터 전환

DB 6번 마이그레이션은 기존 내부 결정 정산 테이블에 자동 계산 여부를 추가한다. 기존 직접 입력 수령액·날짜·장부 ID는 유지한다. 기존 클리어 기록에 수익이 없으면 저장 가격과 인원으로 수익을 채운다. 수정 시각이 그 주차에 속하면 KST 날짜를 사용하고, 그 밖에는 주차 시작일로 기록한다. 필요하면 화면에서 날짜를 수정한다.

기존 직접 입력 수령액은 메모·날짜 수정과 반복 체크로 덮어쓰지 않는다. 난이도·인원을 바꾸면 새 자동 계산 금액으로 전환한다. 체크 해제 후 다시 체크해도 자동 가격을 사용한다. 화면에서는 기존 기록도 동일한 반영 수익으로 표시한다.

내부 `crystal_settlements`와 레거시 IPC 이름은 기존 장부 참조와 호환을 위해 유지한다. 사용자 화면은 판매/미판매를 분류하지 않는다. DB 전환은 거래를 중복 생성하지 않으며 이전 완료·판매·드랍 기록을 보존한다.

## 구현과 검증

- 목록·가격: `shared/boss-catalog.ts`, `shared/crystal-prices.ts`
- 계약: `shared/contracts/boss.contract.ts`
- 저장·업무: `backend/modules/bosses/boss.repository.ts`, `boss.service.ts`
- 집계: `backend/domain/boss-profit.ts`, `backend/modules/ledger/ledger.repository.ts`
- DB 전환: `backend/database/migrations/006_boss_clear_income.sql`
- 화면: `BossesPage.tsx`, `BossRunGroups.tsx`, `BossRunForm.tsx`, `BossIncomeDateForm.tsx`

테스트는 즉시 수익, 중복 체크, 날짜 경계, 인원 수정, 체크 취소·삭제, 0 메소, 장부 실패 롤백, 직접 입력 금액 보존과 기존 DB 전환을 확인한다. Electron에서는 판매 UI 제거, 체크·인원 수정·체크 해제·삭제에 따른 실제 장부 반영과 재실행 보존을 임시 DB로 검증했다.

날짜 전용 수정은 자동·직접 입력 금액과 거래 ID 보존, 인원 확인 상태 유지, 같은 날짜 반복 저장, 날짜 범위·동시 변경 검증과 장부 실패 롤백을 테스트한다. Electron 임시 DB에서 날짜 표시·전용 창 저장·원래 주차와 금액 유지·대시보드 집계 날짜 변경을 확인했다.

주차 직접 추가·보스 교체 테스트는 기존 주차 기록 보존, 중복 보스·미래 주차 차단, 12개 상한과 생성 롤백, 교체 시 수익 재계산·거래 ID 보존, 연결 드랍 보호를 확인한다. Electron 임시 DB에서 서버·캐릭터 그룹, 정보 클릭 수정, 난이도별 인원 선택, 추가·빨간 × 삭제와 빈 캐릭터의 추가 버튼도 검증했다.

[API 보스 클리어](boss-api-sync.md)는 일괄 확인으로 등록된 API 연결 캐릭터들의 완료 보스를 자동 등록하고 결정 수익까지 반영한다. 새 보스는 1인 기준이며 다인 파티는 기록 수정에서 조정한다. 목요일 00시(KST) 이후 새 주차에 기록하고 과거 수익과 수동 기록을 보존한다. 개별 조회·선택 반영과 완료 목록 교체도 사용할 수 있다. 교체 시 기존 수익·드랍이 연결된 기록은 보호한다. 일간 보스, 월드·계정 공통 보상과 게임 내 처치·판매 수량 제한은 자동 검증하지 않는다. 주차 리셋과 [보스·난이도·가격 근거](boss-catalog.md)는 별도 문서에 정리했다.
