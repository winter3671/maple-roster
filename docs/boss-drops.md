# 보스 드랍 선택과 일괄 기록

클리어한 주간 보스의 **드랍 관리 → 획득 아이템 추가**에서 해당 보스의 주요 보상을 선택한다. **+ 아이템 추가**로 여러 종류를 함께 기록하고, 같은 아이템이 여러 개라면 한 줄에서 수량을 늘린다. 한 번에 1~20종류, 각 종류당 1~1,000,000개를 저장할 수 있다. 목록에 없는 아이템은 **기타 · 직접 입력**을 사용한다.

기본 입력은 아이템·수량뿐이다. **예상 단가·메모 추가**를 선택하면 각 항목에 참고 가격과 메모를 입력할 수 있다. 예상 단가는 기본 0이며 자동 시세 조회는 하지 않는다. 획득 기록만 저장하면 실제 수익은 늘지 않는다. 저장 후 아이템별 **판매 기록**에서 실제 판매대금·수수료·분배 인원을 입력하면 내 몫이 기존 거래 장부에 반영된다. 부분 판매와 판매 수정·취소도 기존 방식을 사용한다.

## 목록과 상자 보상

2026-10-09에 확인한 메이플스토리 공식 [보스별 주요 보상 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/459)를 기준으로 앱에 등록된 24개 주간 보스의 주요 보상 후보를 정리했다. 공식 가이드는 보스별로 보상을 묶으므로 이 목록은 난이도별 전체 드랍표나 거래 가능 여부를 보장하지 않는다. 실제 획득한 아이템만 선택한다. 신규·누락 보상은 직접 입력할 수 있다.

[공식 업데이트의 혼돈의 칠흑 장신구 상자 안내](https://maplestory.nexon.com/News/Update/779)를 참고해 해당 상자 보상이 있는 보스에는 개봉 결과인 칠흑 아이템 후보를 함께 표시한다. 선택지의 **칠흑 상자 개봉 결과** 문구로 구별하며 저장 이름은 실제 선택한 아이템 이름이다. 상자 자체와 개봉 결과를 이중으로 기록하지 않는다. 앱이 상자 개봉 결과를 추정하거나 무작위 생성하지 않는다.

## 저장과 기존 기록

- 항목별 UUID를 유지해 같은 내용의 저장 재시도로 중복 획득을 만들지 않는다. 같은 요청 ID의 내용이 바뀌면 충돌로 처리한다.
- 중복 아이템 이름·요청 ID와 잘못된 수량은 거부한다. 여러 항목은 하나의 트랜잭션에서 저장하므로 뒤쪽 항목이 실패하면 앞쪽 항목도 롤백한다.
- 보스·난이도 표시에는 해당 보스 기록을 사용하며, 획득 묶음의 기본 분배 인원은 저장 당시 보스 인원을 복사한다. 판매 시 실제 분배 인원을 조정할 수 있다.
- 선택 목록을 나중에 수정해도 저장된 아이템 이름·수량·가격·메모와 기존 판매 기록은 유지한다.
- 기존 `drop_lots`·`drop_sales` 저장 구조와 백업을 사용한다. DB 마이그레이션은 추가하지 않는다. 사냥의 조각·젬스톤 자동 재고 및 판매 화면은 유지한다.

관련 파일: `shared/boss-drop-catalog.ts`, `frontend/features/drops/BossDropForm.tsx`, `backend/modules/drops/drop.service.ts`.

검증: 통합 테스트에서 수량·분배 수익, 재시도 중복 방지, 실패 시 전체 롤백, 잘못된 입력·출처·미클리어 차단을 확인했다. 별도 임시 장부의 Electron 앱에서 다중 선택, 중복 안내, 직접 입력과 판매 수익 반영을 확인했다.
