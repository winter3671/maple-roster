# 수익 대시보드

대시보드는 거래 장부에 반영된 실제 수입·지출·순수익을 조회합니다. 처음 열면 이번 달 1일부터 오늘까지 전체 캐릭터를 표시합니다. 날짜는 한국 시간(KST) 기준입니다.

## 조회 방법

- **이번 주**: 이번 목요일부터 오늘까지입니다.
- **지난주**: 지난 목요일부터 이번 주 수요일까지입니다.
- **이번 달 / 지난달**: 이번 달은 오늘까지, 지난달은 마지막 날까지입니다.
- 시작일·종료일·캐릭터를 직접 선택하고 **조회**를 눌러 적용할 수도 있습니다.
- 상단 기간 버튼은 적용한 캐릭터 필터를 유지합니다. 전체 비교로 돌아가려면 **전체 캐릭터**를 선택하고 조회하세요.
- **새로고침**은 저장된 장부와 캐릭터 목록을 다시 읽습니다. 넥슨 API 보스 완료 조회는 보스 장부에서 실행합니다.

## 표시 내용

수입·지출·순수익 합계 아래에서 기간별 추이를 확인합니다. 62일 이하 기간은 일별, 더 긴 기간은 월별로 묶으며 거래가 없는 날짜·달도 0으로 표시합니다. 부분 월을 조회하면 선택한 날짜의 거래만 포함합니다.

초록 막대는 순수익, 빨강 막대는 손실입니다. 막대를 클릭하거나 키보드로 선택하면 해당 날짜·달의 수입·지출·순수익과 거래 건수가 표시됩니다. 긴 그래프는 가로로 스크롤할 수 있습니다.

사냥·결정석·드랍 판매·직접 지출별 합계와 캐릭터별 수익을 함께 제공합니다. 캐릭터 표는 순수익이 높은 순서이며 이름을 누르면 해당 캐릭터의 같은 기간으로 조회합니다. 이름이 같은 캐릭터도 내부 ID로 구분합니다. 숨긴 캐릭터의 거래도 포함하며 이름은 현재 등록 이름, 서버는 거래 당시 서버를 표시합니다. 서버 이동 전후의 기록은 같은 캐릭터로 합산합니다.

최근 거래에는 적용한 조회 조건의 최신 5건이 표시됩니다. 거래 건수는 장부 항목 수이며, 수입과 소모 비용이 함께 있는 사냥 회차는 각각 집계됩니다.

## 집계 기준

사냥 획득 메소와 비용은 사냥 날짜, 결정석은 수익 반영일, 드랍 판매는 판매일, 직접 지출은 입력한 지출 날짜 기준입니다. 보스 주차별 클리어 수익과 날짜별 대시보드 합계는 반영일에 따라 달라질 수 있습니다.

화면에도 결정석이 실제 처치일이 아닌 장부 반영일 기준이라는 안내를 표시합니다. API로 새로 확인한 결정석 수익은 현재 주차에서는 조회일, 과거 주차에서는 주차 시작일을 사용합니다. 기존 수익의 날짜는 반복 조회해도 유지합니다. 보스 장부의 수익 아래 날짜를 눌러 반영일을 수정하면 대시보드에서도 변경한 날짜로 집계됩니다. 보스가 속한 원래 주차는 유지됩니다.

드랍 판매는 수수료·파티 분배 후 실제 내 몫을 집계합니다. 미판매 아이템의 예상 가치와 API에서 아직 반영하지 않은 완료 상태는 실제 순수익에 포함하지 않습니다. 모든 집계는 기존 거래 내역과 같은 장부 데이터를 사용합니다.
