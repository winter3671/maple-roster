# 메이플포인트 지출

거래 내역의 지출 추가·수정에서 통화를 선택한다. 기본은 메소이며 기존 지출도 메소로 유지한다. 메이플포인트 선택 시 사용 포인트와 메소마켓의 1억 메소당 포인트를 양의 정수로 입력한다. 시세는 자동 조회하거나 이전 기록에 소급 적용하지 않는다.

환산 금액은 `사용 포인트 × 100,000,000 ÷ 환전비`이며 1메소 미만을 버린다. BigInt로 계산해 곱셈 중 정밀도 손실을 막고 결과가 1~9,007,199,254,740,991 메소인지 검증한다. 프론트엔드의 금액 미리보기를 신뢰하지 않고 백엔드가 원본 포인트·환전비로 다시 계산한다.

DB 13번 마이그레이션은 직접 지출에 currency, point_amount, points_per_100m을 추가한다. amount는 메소 환산 금액으로 유지하여 기존 장부·대시보드·순수익 집계를 그대로 사용한다. 수정 시 동일 거래 ID를 갱신하고 메소로 통화를 바꾸면 포인트 관련 값은 비운다. 날짜·분류·메모·캐릭터 처리와 반복 저장 방지는 기존 규칙을 따른다.

CSV 끝에 지출 통화·사용 메이플포인트·1억 메소당 메이플포인트 열을 추가하고 기존 메소 금액·순수익 열은 유지한다. JSON 백업에 원본 값을 보관하며 복원 시 환산 금액의 일치를 검증한다. 12번 이하 백업의 직접 지출은 메소와 비어 있는 포인트 필드로 복원한다.
