# 작업 진행과 결과 알림

사용자가 시작한 API 조회·캐릭터 일괄 등록·백업과 복원·거래 CSV 저장은 오른쪽 아래에 공통 알림을 표시한다. 페이지의 상세 오류와 캐릭터별 결과 표는 유지한다. 앱 업데이트는 기존 다운로드 진행률과 재시작 안내를 사용한다.

## 표시 규칙

- 진행 중: 처리 표시를 보여 주며, 실제 진행률을 제공하지 않는 API에 임의의 퍼센트를 표시하지 않는다.
- 완료: 정상 종료 후 8초 동안 표시한다. 닫기 버튼으로 먼저 숨길 수 있다.
- 일부 확인 필요: 일부 캐릭터 실패·미처리 또는 저장 이후 화면 갱신 실패를 알린다.
- 실패: 작업 실패를 알린다. 상세 이유와 재시도는 해당 화면에서 확인한다.
- 일부 확인 필요와 실패는 자동으로 숨기지 않는다. 종료된 알림은 최근 3개만 유지한다. 진행 중인 작업은 이 제한으로 제거하지 않는다.
- 파일 선택을 취소하면 알림을 제거한다. 성공으로 안내하지 않는다.

주간 콘텐츠의 저장된 기록 조회, 주차 변경 확인, 자동 백업 상태의 주기적 확인, 캐릭터 프로필의 자동 갱신에는 알림을 띄우지 않는다. 실제 자동 백업 동작은 변경하지 않는다.

## 이동과 종료 보호

알림 저장소는 페이지 바깥에서 유지된다. 알림 대상 작업이 실행 중이면 메뉴 이동·수정창 닫기·정상 종료 시 완료를 기다리도록 안내한다. 작업 결과가 나온 뒤 다시 이동할 수 있다. 폼 저장 보호와 동일한 확인 창을 사용하고, 확인 시점에도 실행 중인 작업을 다시 검사한다.

완료 알림은 다른 메뉴로 이동해도 남는다. 작업 결과나 키를 저장하지 않고 제목·표시 상태·사용자용 요약만 메모리에 보관한다. 공통 실패 알림에는 API 응답의 원문을 넣지 않는다.

## 검증

`task-notifications.test.ts`에서 즉시 실행 상태 등록, 복수 작업 보호, 취소, 중복 완료, 8초 만료, 실패 유지, 최근 3개 제한, 구독 해제와 일괄 처리 결과 분류를 검증한다. 실제 Electron 화면에서는 별도 임시 장부로 진행 중 이동·종료 보호, API 일부 실패, 정상 완료, 백업 취소와 실패 안내를 확인한다.
