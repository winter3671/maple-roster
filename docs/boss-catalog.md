## 화면과 저장 규칙

- 보스를 선택하면 해당 난이도만 표시한다. 노멀 난이도가 있으면 기본 선택하고, 없으면 첫 난이도를 선택한다.
- 새 프리셋에서 보스를 변경하면 이전 보스의 가격이 적용되지 않도록 새 보스·난이도의 가격을 자동 조회한다.
- 프리셋 수정에서는 기존 캐릭터·보스를 유지하고 난이도·파티 인원을 수정한다. 가격은 자동 계산한다. 주차 기록 수정에서도 그 보스의 난이도만 선택한다.
- 신규 등록과 난이도 변경은 backend에서도 목록과 최대 인원을 검증한다.
- 과거 자유 입력 이름·난이도는 DB를 변경하지 않는다. 목록 밖 값은 ‘기존 기록’ 옵션으로 표시하고 그대로 유지한 상태의 수정·정산을 허용한다. 기존 이름이 목록에 없으면 새로운 난이도를 임의로 추가할 수 없다.

정의는 `src/shared/boss-catalog.ts`에 두고 frontend와 backend가 함께 사용한다. 보스·난이도 추가 시 이 파일과 확인 날짜·출처를 갱신한다. 자동 갱신은 하지 않는다. DB 마이그레이션은 필요하지 않다.

## 결정석 가격표

`src/shared/crystal-prices.ts`에 52개 보스·난이도 조합의 1인 기준 가격을 저장한다. `floor(1인 기준 가격 / 클리어 인원)`으로 예상 내 몫을 구하며 frontend 미리보기와 backend 저장에 같은 가격표를 사용한다. 입력으로 전달된 임의의 가격은 새 프리셋의 가격을 바꾸지 못한다.

- 2026-06-18부터 2026-09-16: [6월 본 서버 업데이트](https://maplestory.nexon.com/News/Update/806)의 변경 가격을 적용한다. 변경 표에 없는 낮은 보스 가격은 [보스 도감](https://maplewhoru.kr/boss/)과 대조했다.
- 2026-09-17 이후: [9월 본 서버 업데이트](https://maplestory.nexon.com/News/Update/813)의 변경 가격을 적용한다. 카링 노멀은 593,000,000, 찬란한 흉성 노멀은 576,000,000 메소다. 테스트 서버 표가 아닌 수정된 본 서버 공지를 따른다.
- 벨로나는 2026-08-20부터 지원한다. 하드 2,950,000,000 메소는 공식 공지에 가격이 없어서 [가격 정리표](https://matsu1207.tistory.com/m/757)와 [Maple Week](https://www.maple-week.com/)로 교차 확인했다. 8월 21일 하드 개방은 시간 단위로 검증하지 않는다.

프리셋은 현재 날짜의 가격을 사용하고, 새 주차는 주차 시작일의 가격을 저장한다. 기존 주차는 반복 생성·메모·인원 수정으로 가격을 덮어쓰지 않는다. 주차 난이도를 바꾸면 해당 주차의 새 난이도 가격을 적용한다. 가격표 이전 날짜의 새 주차 생성은 명확한 오류를 반환하고 기존 과거 기록은 그대로 조회·수정한다. 목록에 없는 기존 이름·난이도는 저장 가격을 유지한다. 클리어를 체크하면 계산 금액을 즉시 수입으로 반영한다. 난이도·인원 수정 시 수익도 갱신하고 체크 해제 시 취소한다. 기존 직접 입력 수령액은 보존한다.

기본 가격표 확인일은 2026-10-08이다. 설정의 **결정석 가격표 관리**에서 적용일·확인일·출처와 함께 수동 가격을 추가하고 수정·삭제할 수 있다. 날짜 이하의 가장 최근 이력을 사용하고 같은 적용일의 수동 가격을 우선한다. 기존 저장 가격은 보존하고 수동 이력도 JSON 백업에 포함한다. 자동 API 가격 조회는 아니다. 상세 규칙은 [결정석 가격 이력](crystal-price-history.md)을 참고한다.
