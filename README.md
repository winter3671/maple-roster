# Maple Roster

메이플스토리 캐릭터들의 보스·사냥 수입과 지출을 기록하는 개인용 Electron 데스크톱 앱입니다.

여러 캐릭터의 기록을 한곳에 모아 캐릭터별·기간별 실제 순수익을 확인하는 것을 목표로 합니다. NEXON Open API로 캐릭터 정보와 보스 완료 상태를 조회하고, 판매·분배 금액은 장부에 기록하는 방식으로 기획하고 있습니다.

프론트엔드와 백엔드를 분리하고, 화면 입력부터 요청 검증·업무 처리·DB 저장까지 직접 구현하며 연습하는 프로젝트입니다.

## 현재 상태

**캐릭터 관리, 사냥 장부와 넥슨 캐릭터 조회를 사용할 수 있습니다.** 캐릭터를 수동 등록하거나 본인 계정의 API 목록에서 선택한 뒤 사냥 회차를 추가·수정·삭제할 수 있으며, 앱을 다시 열어도 장부가 유지됩니다. 획득 메소와 소모 비용은 거래 내역에 자동 반영되고, 날짜·캐릭터별 순수익과 시간당 수익을 조회할 수 있습니다. 대시보드는 이번 달의 실제 장부 합계를 표시합니다. 보스 장부와 API 프로필 자동 동기화는 다음 단계이고, 설치 파일은 아직 제공하지 않습니다.

사냥 기록은 날짜, 시간(분), 직접 획득한 메소, 소모 비용, 솔 에르다 조각·코어 젬스톤 수량과 메모를 입력합니다. 아이템 수량은 메소 수입에 포함하지 않습니다. 시간이 0분인 기록은 시간당 계산에서 제외하며, 여러 회차의 시간당 순수익은 시간이 기록된 회차의 총 순수익 ÷ 총시간으로 계산합니다. 시간당 메소는 소수점 이하를 내림합니다.

## 주요 기능 계획

| 기능        | 내용                                                            |
| ----------- | --------------------------------------------------------------- |
| 캐릭터 관리 | 캐릭터 등록, 프로필 조회, 표시 순서와 숨김 설정                 |
| 보스 장부   | 캐릭터별 보스 프리셋, 클리어 확인, 결정석 판매와 드랍 분배 기록 |
| 사냥 장부   | 회차별 사냥 시간, 획득 메소, 드랍 수량과 소모 비용 기록         |
| 거래 내역   | 아이템 판매, 기타 수입과 구매·강화 등 지출 기록                 |
| 대시보드    | 주간·월간 순수익, 캐릭터별 합계와 수익 추이                     |
| 데이터 관리 | 로컬 자동 저장, JSON 백업·복원과 CSV 내보내기                   |

첫 버전은 개인용 로컬 앱으로 개발합니다. 다른 유저에게 배포하는 기능과 클라우드 동기화는 후속 단계에서 고려합니다.

## 수익 기록 원칙

- 실제 순수익은 판매·수령이 확정된 수입에서 실제 지출을 뺀 값입니다.
- 미판매 아이템의 수량과 예상 가치는 실제 메소 수입과 따로 표시합니다.
- 보스 클리어 상태와 결정석 판매·드랍 정산 상태를 구분합니다.
- 기록 당시 단가·수수료·분배 결과를 보존하여 이후 설정 변경이 과거 수익을 바꾸지 않도록 합니다.
- 같은 기록의 반복 조회나 판매 정산이 수입을 중복 생성하지 않도록 합니다.
- 기간 집계는 한국 시간(KST)을 기준으로 하고 과거 기록을 유지합니다.

## 기술 구성 계획

| 영역        | 기술                                            |
| ----------- | ----------------------------------------------- |
| 데스크톱    | Electron                                        |
| 프론트엔드  | React, TypeScript, Tailwind CSS v4              |
| 백엔드      | TypeScript, SQLite (Node.js 내장 `node:sqlite`) |
| 개발 빌드   | electron-vite                                   |
| 테스트      | Vitest                                          |
| 게임 데이터 | NEXON Open API                                  |

현재 의존성은 `package-lock.json`으로 고정합니다. 빌드는 electron-vite 5와 호환되는 Vite 7을 사용합니다. DB는 Electron에 포함된 Node.js의 내장 SQLite를 사용하므로 별도 네이티브 드라이버 재빌드가 필요하지 않습니다.

## 프로젝트 구조

```text
src/
├─ frontend/   # React 화면, 입력 폼, Tailwind 스타일
├─ backend/    # 업무 처리, 수익 계산, DB 저장, 넥슨 API 연동
├─ desktop/    # Electron 창 관리, preload, IPC 연결
└─ shared/     # 호출 계약, DTO, 오류 코드, 입력 검증
```

백엔드는 Electron main 프로세스에서, 프론트엔드는 renderer 프로세스에서 실행합니다. 두 영역은 preload가 제공하는 제한된 API와 IPC를 통해 연결합니다. 앱 정보, 캐릭터 관리, 사냥 회차 관리와 거래 내역 조회 호출이 연결되어 있습니다. 사냥 회차와 연결된 거래는 하나의 DB 트랜잭션으로 저장·수정·삭제합니다.

```text
화면 입력 → preload / IPC → 요청 검증 → 백엔드 서비스 → 계산·DB 저장 → 결과 표시
```

백엔드의 서비스는 업무 흐름을, 저장소(repository)는 SQL 실행을, 계산 함수(domain)는 수익·분배·기간 규칙을 담당합니다. Electron 전용 코드는 desktop 영역에 두어 업무 코드와 분리합니다.

## 실행 안내

Node.js 24 이상과 npm이 필요합니다. Git Bash에서 프로젝트 폴더로 이동해 실행하세요.

```bash
npm ci
npm run dev
```

이미 의존성을 설치했다면 `npm run dev`만 실행하면 됩니다. Electron 창이 열리며, React 코드를 수정하면 개발 화면에 반영됩니다. 종료할 때는 앱 창을 닫고 터미널에서 `Ctrl+C`를 누르세요.

```bash
# 타입 검사
npm run typecheck

# 캐릭터·사냥 저장, 수익 계산과 입력 검증 테스트
npm test

# 타입 검사와 프로덕션 빌드
npm run build

# 빌드한 앱 실행 (설치 파일 생성은 아직 지원하지 않습니다)
npm start

# 코드 포맷 검사와 자동 정리
npm run format:check
npm run format
```

PowerShell에서 npm 스크립트 실행이 차단된다면 같은 명령의 `npm`을 `npm.cmd`로 바꾸어 실행할 수 있습니다.

## API와 데이터 보관 계획

프로젝트 루트에서 `.env.example`을 `.env`로 복사하고 `NEXON_API_KEY=발급받은키`를 입력합니다. `.env`와 `.env.*`는 Git에서 제외하고, 값이 없는 `.env.example`만 공유합니다. 키 변수에 `VITE_` 접두사를 붙이지 않습니다. 앱은 개발·빌드 미리보기 실행 시 Electron main 프로세스에서만 `.env`를 읽습니다. 키를 변경하면 앱과 개발 서버를 종료한 뒤 다시 실행해야 합니다.

실행 후 **설정 → API 연결 테스트**로 연결을 확인하고, **캐릭터 관리 → 내 캐릭터 불러오기**에서 이름·월드·직업으로 검색합니다. 원하는 캐릭터를 체크한 뒤 **선택한 N개 등록**으로 한 번에 장부에 추가합니다. **검색 결과 전체 선택**은 현재 검색 결과의 미등록 캐릭터만 추가로 체크하며, 검색 조건을 바꿔도 기존 선택은 유지됩니다. **선택 해제**는 전체 선택을 지웁니다. 이미 등록된 캐릭터는 숨김 여부와 함께 표시하고 선택에서 제외합니다. 캐릭터 옆 **정보** 버튼으로 레벨·직업·길드를 별도로 조회할 수 있습니다.

일괄 등록 결과는 신규·이미 등록·실패·미처리 개수로 표시합니다. 성공한 기록은 유지하고 실패·미처리 캐릭터만 체크 상태로 남겨 재시도할 수 있습니다. 기존 같은 이름·월드의 캐릭터는 ID·메모·숨김 상태와 연결 기록을 유지합니다. 조회한 목록·프로필은 화면에서만 유지하며, OCID 연결 및 레벨·직업의 영구 저장과 자동 동기화는 후속 단계입니다.

API 키 없이도 수동 장부를 사용할 수 있습니다. 현재 개발용 `.env`는 평문 파일이며 앱의 DB·로그·화면·빌드에 키를 복사하지 않습니다. 배포용 키 입력과 Electron `safeStorage` 암호화 보관은 아직 구현하지 않았습니다. 패키징한 앱은 개발용 `.env`를 읽지 않습니다.

캐릭터와 장부는 앱 데이터 폴더의 `data/maple-roster.sqlite`에 저장됩니다. 같은 이름·월드의 중복 등록을 막으며, 숨김은 데이터를 유지하고 일반 캐릭터 목록에서 제외합니다. 숨긴 캐릭터의 과거 사냥 기록은 계속 조회할 수 있습니다. 삭제는 확인 후 영구 반영됩니다. 사냥 기록이 연결된 캐릭터는 삭제할 수 없으며, 숨김을 사용할 수 있습니다. 기존 캐릭터 DB는 실행 시 새 장부 구조로 자동 업데이트합니다.

사냥 시간·획득 메소·드랍 수량·실제 판매 금액은 직접 기록하고, API는 프로필과 완료 상태 조회를 보조하도록 개발합니다.

확인한 공식 스케줄러 명세에 따르면 본인 계정 캐릭터만 조회할 수 있고, 과거 조회는 요청일 기준 최대 14일 전까지 가능합니다. 장기 기록은 앱에 별도로 보존합니다. 자세한 내용은 [넥슨 스케줄러 API](https://openapi.nexon.com/ko/game/maplestory/?id=57)와 [확인한 명세](docs/references/nexon-scheduler.yaml)를 참고하세요.
